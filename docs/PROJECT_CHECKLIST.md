# RepuShield Project Checklist

Complete phases in order. Do not skip verification.

## Phase 0 — Before coding

- [ ] Create a dedicated project folder, e.g. `RepuShield`.
- [ ] Open the folder in Antigravity.
- [ ] Add this starter documentation to the project root.
- [ ] Confirm whether Lovable's generated project will be used as a visual/code reference or whether development starts fresh.
- [ ] Confirm logo availability; use a temporary text mark until the real logo is ready.
- [ ] Request final service descriptions and pricing from the client.
- [ ] Confirm whether the client has real testimonials/case studies; otherwise use no fabricated proof.
- [ ] Confirm the client approves the public-facing wording and disclaimers.

## Phase 1 — Inspect environment and plan

- [ ] Ask the coding agent to inspect the folder and environment only.
- [ ] Review the proposed stack and folder structure.
- [ ] Confirm React + Vite + TypeScript unless the existing project has a sound alternative.
- [ ] Confirm compatible Tailwind setup for the selected version.
- [ ] Confirm routing and animation library choices.
- [ ] Approve the implementation plan before files are changed.

## Phase 2 — Project foundation

- [ ] Create/verify the React app.
- [ ] Install only required dependencies.
- [ ] Run the development server.
- [ ] Confirm the starter page loads.
- [ ] Configure global styles and design tokens.
- [ ] Configure fonts.
- [ ] Configure routes and a not-found page.
- [ ] Verify no console/build errors.
- [ ] Initialize Git and make the first commit.

## Phase 3 — Shared UI

- [ ] Header/navigation.
- [ ] Footer.
- [ ] Primary and secondary buttons.
- [ ] Container and section layout primitives.
- [ ] Reusable cards.
- [ ] CTA section.
- [ ] FAQ accordion.
- [ ] Form field components.
- [ ] Responsive mobile navigation.
- [ ] Motion/reduced-motion utilities.
- [ ] Check all shared components on mobile and desktop.

## Phase 4 — Public pages

- [ ] Home.
- [ ] About Us.
- [ ] Services.
- [ ] Pricing.
- [ ] Case Studies.
- [ ] Contact Us.
- [ ] FAQ.
- [ ] Google Ads Landing Page.
- [ ] Check page titles and meta descriptions.
- [ ] Check navigation between every page.
- [ ] Verify all claims and business information.

## Phase 5 — Admin dashboard prototype

- [ ] Create `/admin` route.
- [ ] Create separate dashboard layout.
- [ ] Glassmorphism sidebar and top bar.
- [ ] Overview statistic cards with sample labels.
- [ ] Demo charts.
- [ ] Demo inquiry table.
- [ ] Demo activity timeline.
- [ ] Responsive sidebar/table behaviour.
- [ ] Clearly label all data as sample/demo.
- [ ] Do not imply real login, database, or saved data exists.

## Phase 6 — Contact and analytics integrations

- [ ] Choose and configure a real form submission service or backend.
- [ ] Add environment variables securely if required.
- [ ] Add client-side validation.
- [ ] Add loading, success, and error states.
- [ ] Submit a real test inquiry and verify receipt.
- [ ] Verify WhatsApp URL opens the correct number.
- [ ] Verify email link uses the correct address.
- [ ] Configure GA4 after the client supplies/creates the property.
- [ ] Test inquiry and WhatsApp conversion events.
- [ ] Do not expose secrets in frontend code.

## Phase 7 — Quality assurance

- [ ] Desktop visual review.
- [ ] Tablet visual review.
- [ ] Mobile visual review.
- [ ] Check all links and buttons.
- [ ] Check form submission.
- [ ] Check image loading and alt text.
- [ ] Check keyboard navigation and focus states.
- [ ] Check reduced-motion behaviour.
- [ ] Check color contrast.
- [ ] Check browser console.
- [ ] Run production build.
- [ ] Check page titles/meta descriptions.
- [ ] Add Privacy Policy and Terms pages/content as approved.
- [ ] Confirm independent-service/Google disclaimer.
- [ ] Remove placeholder content that should not be public.

## Phase 8 — Deployment and handover

- [ ] Confirm client has approved final preview.
- [ ] Purchase/obtain domain (client cost).
- [ ] Select hosting/deployment target.
- [ ] Configure domain DNS.
- [ ] Verify HTTPS.
- [ ] Verify production form submission.
- [ ] Verify production analytics.
- [ ] Test all pages on the live domain.
- [ ] Provide client with agreed access and handover notes.
- [ ] Collect final payment according to agreement.
- [ ] Record any out-of-scope requests separately.

## Scope guard

The agreed PKR 30,000 scope includes the 8 public pages, responsive design, inquiry form integration, WhatsApp/email links, basic SEO, GA4/conversion tracking setup, and two revision rounds.

Domain, hosting, advertising spend, ad campaign management, production admin authentication/database/CRM, ongoing maintenance, and additional major features are separate unless explicitly agreed in writing.
